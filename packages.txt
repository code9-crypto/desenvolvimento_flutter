PACOTES USADOS NOS PROJETOS
NOTA: todos esses pacotes devem ser inseridos dentro do arquivo pubspec.yaml e depois executado o pub get para baixar esses pacotes no projeto

flutter_slidable: ^3.1.2 -> este pacote é para fazer os slides nos itens numa listView;(a versão usada foi esta)
shared_preferences: ^2.0.8 -> este pacote serve para salvar pequenos textos no próprio celular;(versão usada)
intl: -> é o pacote que faz a formatação da data e hora(este pacote não tem versão)
http: ^0.13.0 -> este é o pacote que faz requisições http(GET, PUT, POST ...) é a versão que funcionou
OBS.: ao fazer alguma requisição use o Uri.parse(request)
path_provider: ^2.1.5 -> este pacote será usado para salvar dados no celular usando JSON
share_plus: ^11.0.0 -> este pacote permite fazer o compartilhamento do conteúdo
transparent_image: ^2.0.1 -> permite fazer uma imagem suave
sqflite: ^2.4.0 -> este pacote faz acesso ao banco de dados usando sqlite
url_launcher: ^6.3.1 -> permite abrir o método de ligação do telefone
image_picker: ^1.1.2 -> permite tirar foto
google_sign_in: ^6.1.4 -> permite fazer a autenticação do google
firebase_storage: ^11.2.3 -> permite acessar o storage do firebase
firebase_auth: ^5.6.0 -> permite fazer autenticação com o firebase
cloud_firestore: ^4.17.5 -> permite acessar o cloud_firestore do firebase
firebase_core: ^2.32.0 -> permite fazer os comandos no firebase
font_awesome_flutter: ^10.8.0 -> este pacote permite incluir ícones mais personalizados
flutter_staggered_grid_view: ^0.7.0 -> este pacote permite mostrar as fotos em formato grade
firebase_analytics: ^11.5.0 -> este pacote permite fazer a análise do banco de dados
firebase_messaging: ^15.2.7 -> este pacote permite fazer envio de mensagens via push
another_carousel_pro: ^1.0.2 -> este pacote permite fazer o slide das fotos
scoped_model: ^2.0.0

IMPORTANTE:
Quando for usar o pacote do shared_preferences no projeto, deverá fazer as seguintes configurações para funcionar no celular

1º no arquivo build.gradle (.../android/app/build.gradle)
....
android{
    ....
    ndkVersion = "25.1.8937393"
    ....

    kotlinOptions {
        jvmTarget = 17
    }
}

2º no arquivo settings.gradle (.../android/settings.gradle)
....
plugins{
    ...
    id "com.android.application" version "8.3.2" apply false
    id "org.jetbrains.kotlin.android" version "2.0.20" apply false
}

3º no arquivo gradle-wrapper.properties (.../android/gradle/wrapper/gradle-wrapper.properties)
....
distributionUrl=https\://services.gradle.org/distributions/gradle-8.10.2-all.zip
