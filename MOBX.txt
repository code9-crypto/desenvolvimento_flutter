******************************************************************************************************************************************************
CRIANDO AÇÕES E ESTADOS

TODO ESTADO É UM OBSERVABLE
Ex.: Observable count = Observable(0) //OBS.: assim que é declarado  um estado e no seu construtor deve ser passado um valor inicial
Observable discount = Observable(0)

ACESSANDO O VALOR DE UM ESTADO E RETORNANDO-O(normalmente por meio de um getter)
int get retonaValorCount => count.value; //este count.value é a forma que acessamos o valor do estado
int get retornValorDiscount => discount.value;

CRIANDO UMA AÇÃO
late Action acao;

CRIANDO A FUNÇÃO QUE SERÁ USADA POR MEIO DA AÇÃO
OBS.: aqui na função é possível chamar outra função a fim de que sejam chamadas duas funções numa mesma ação. Contudo, como são funções diferentes
então deverá ter outro estado diferente; com isso não é necessário criar outra ação, já que a mesma ação chamará duas funções diferentes
void incrementar(){
    count.value++;
    decrementar(); //eu chamo a outra função dentro da função que está vinculada com a ação
}

void decrementar(){
    discount.value--;
} 

CRIANDO O CONSTRUTOR QUE VINCULARÁ A AÇÃO COM A FUNÇÃO
Construtor(){
    acao = Action(incrementar);
}

Classe class = Classe();

onPressed: class.incrementar

OU

onTap: class.incrementar

REAÇÃO

CRIANDO UM OBSERVER PARA QUE SEJA MOSTRADA A REAÇÃO DA AÇÃO
OBS.: essa parte é feito dentro da classe que mostrará o widget
Observer(
    OBS.: qualquer uma das duas formas vai retornar o widget da reação
    builder: (context) => Text($class.retonaValorCount) -> ao invés de acessar o valor no estado direto, eu uso o getter que já vem com essa valor
    
    OU

    builder: (context){
        return Text($class.retornValorDiscount) -> ao invés de acessar o valor no estado direto, eu uso o getter que já vem com essa valor
    }
)

********************************************************************************************************************************************************
USANDO NOTAÇÕES PARA TORNAR O CÓDIGO MAIS LIMPO

tornando uma variavel ser um observavel / estado
@observable
int count = 0;
@observable
int discount = 0;

tornando uma função ser uma ação
@action
void increment(){
    count++;
}

OU

@action
void setCount(valor) => count++;

este(normalmente é um get) retorna um valor quando um ou mais valores(observables/estados) combinados atendem a determinado critério
OBS.: esta notação é o retorno dos valores dos estados( ou o retorno da combinação dos valores )
@computed
bool get isFormValid => count > 10 && discount == -10 -> neste o retorno será um valor true ou false
IMPORTANTE: todos os @computed devem ser do tipo get, caso contrário não irá funcionar

********************************************************************************************************************************************************
MESCLANDO A CLASSE GERADA( PELO GERADOR DE CÓDIGO ) COM A CLASSE ABSTRATA( A QUAL TEM AS NOTAÇÕES )
//Quando o gerar de código for executado, ele criar um arquivo com o nome da classe + essa nomenclatura
part 'nome_classe.g.dart';

//Depois que ela for criada nós temos que mesclar aquela classe com esta
//E para fazer isso é deste jeito
class NomeClasse = _Classe with _$Classe;

//Depois disso tudo(acima) temos que dar um with Store na classe com as notações usadas
abstract class _NomeClasse with Store{}

********************************************************************************************************************************************************
AUTORUN -> ele é executado toda vez que algum observable, dentro deste autorun, for modificado
obs.: este comando é usado dentro do contrutor da classe;

class Classe{
    Classe(){
        autorun((_) {
            print(count);
        })
    }

    @observable
    int count = 0;
}
