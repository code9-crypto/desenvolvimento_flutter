PARÂMETROS DE FUNÇÕES
Para que seja possível "setar" um valor padrão e seja também opcionail,
apenas coloque o parâmetro entre colchetes [] e atribua um valor a ele;
NOTA: Dentro desses colchetes pode colocar mais de uma variável, porém
para que seja possível passar o valor ao segundo parâmetro sem passar pelo primeiro,
ocorrerá erro; então nesse caso deverá passar o valor a todos os parâmetros para que não haja erros;

Caso queria faze-lo de forma aleatória, ou seja, sem seguir a ordem dos parâmetros, é possível deixar os parâmetros entre chaves {}, porém agora
quando for chamar a função, a forma de passar os parâmetros devem ser nomeados;
Ex.:void main(){
	funcao(nome: "William", idade: 32);
}

funcao({String nome, int idade}){
	print("Olá $nome, sua idade é $idade);
}

PALAVRA CHAVE "SUPER"
Antes de mais nada devemos entender que, NÃO É POSSÍVEL ACESSAR MÉTODOS DE UMA SUBCLASSE
Para que seja possível que um método da subclasse seja executada, primeiramente criamos o método na SUPERCLASSE e após
criamos o mesmo método na SUBCLASSE(com a mesma assinatura), porém com a anotação @override em cima deste método da SUBLCASSE;
Agora para fazer acesso aos métodos da SUPERCLASSE devemos usar o "super." e o nome do método;
Ex.: Ex.: class Pessoa{
	void andar(){
		print("Andando...");
	}

	void correr(){
		print("Estou correndo");
	}
}

class PessoaFisica extends Pessoa{
	@override
	void andar(){
		print("Andando com pessoa física);
	}

	@override
	void correr(){
		super.correr();
		print("Continuo correndo...");
	}
}

E para que o construtor da SUBCLASSE passe os valores aos atributos da SUPERCLASSE, fazemos assim:
Ex.: Ex.: class Pessoa{
	Pessoa(this.nome, this.idade)
	
	String nome;
	int idade;
}

class PessoaFisica extends Pessoa{
	PessoaFisica(String nome, int idade) : super(nome, idade);
}

INTERFACES
Uma interface é declarada como uma classe abstrata(abstract class ...), mas na hora de reutilizá-lo usamos a palavra reservada
implements(como se fosse cumprir um contrato);
Toda classe que cumpre este contrato, obrigatoriamente deve usar seus métodos;
DETALHE: A lógica não fica dentro da interface, mas sim dentro da classe que cumpre seu contrato

Ex.:
OBS.: Na declaração da variável pode utilizar o tipo de dado como a interface, porém na instanciação deverá ser a classe
que implementa a interface.(já que não é possível instanciar classes abstratas)
void main() {
  RepositorioPessoas pessoas = RepositorioPessoasLocal();
  print(pessoas.ler(5));
  
}

//Aqui é considerado um interface
//A lógica não fica na interface
abstract class RepositorioPessoas {
  String ler(int i);
  void adicionar(String nome);
  void apagar(int i);
  void apagarTodos();
}

//Para implementá-lo é feito deste jeito
//E toda a lógica fica dentro da classe que cumpre o contrato da interface
class RepositorioPessoasLocal implements RepositorioPessoas {
  @override
  void adicionar(String nome) {}

  @override
  void apagar(int i) {}

  @override
  void apagarTodos() {}

  @override
  String ler(int i) {
    return "Lendo seus dados...";
  }
}
