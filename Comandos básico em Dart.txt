É uma linguagem que é fortemente tipada, ou seja, deve declarar o tipo
da variável antes do nome;
Exemplos:
int idade = 30;
String nome = "William";
...

OBS.: É possível fazer a multiplicação de caracteres assim:
"A" * 20 -> aqui vai gerar 20 letras A

PARÂMETROS DE FUNÇÕES
Para que seja possível "setar" um valor padrão e seja também opcionail,
apenas coloque o parâmetro entre colchetes [] e atribua um valor a ele;
NOTA: Dentro desses colchetes pode colocar mais de uma variável, porém
para que seja possível passar o valor ao segundo parâmetro sem passar pelo primeiro,
ocorrerá erro; então nesse caso deverá passar o valor a todos os parâmetros para que não haja erros;

Caso queria faze-lo de forma aleatória, ou seja, sem seguir a ordem dos parâmetros, é possível deixar os parâmetros entre chaves {}, porém agora
quando for chamar a função, a forma de passar os parâmetros devem ser nomeados;
Ex.:void main(){
	funcao(nome: "William", idade: 32);
}

funcao({String nome, int idade}){
	print("Olá $nome, sua idade é $idade);
}

VALORES NULOS / NULL
Para que uma variável/parâmetro seja null, apenas específique o símbolo de ? depois do tipo da variável:
Ex.: String? nome

OPERADOR TERNÁRIO
double nota = 8.5;
String mensagem = nota >= 6 ? "Aprovado" : "Reprovado"

OBS.: Para que seja possível uma variável receber um valor se for nulo ou que tenha valor utílizavel, usamos o operador ??;
Ex.: String cliente = nome ?? "não informado" -> Caso a variável nome tenha valor, então cliente receberá o valor da variável nome;
Caso a variável nome seja nulo ou undefined, então a variável cliente receberá o valor "não informado"

FUNÇÕES ANÔNIMAS
É passar uma função como parâmetro de outra função:
Ex.:
void main() {
  saudacoes(
    "William",
    corpo: (i){
    for( int j = 1; j <= i; j++ ){
      print("Olá $j");
    }
  });
}
o parâmetro corpo está recebendo uma função anônima

VARIÁVEIS DINÂMICAS
var -> é uma forma de declarar variável que não tem tipo específico, contudo se a variável iniciar com determinado tipo,
ela não poderá ser alterada para outro tipo no decorrer do script;
Ex.: var nome = "William";
var nome = 2; -> aqui causará um erro, portanto use apenas em casos muito específicos

dinamyc -> é uma forma de declarar variável que não tem tipo específico, mas este tipo aceita a troca do valor dentro da variável;
Ex.: dinamyc teste = "texto";
teste = 2 -> diferente da de cima, aqui não ocorrerá um erro, todavia não usa-a o tempo todo, faça isso em cenários muito específicos
para que não haja possível fatal erro no aplicativo;

num -> é uma forma de declarar variável que aceita apenas número, tanto inteiro como decimal e também pode ser alterado um pelo outro
no decorrer do script sem que haja erro;
Ex.: num numero = 50; 
num numero = 6.5;

LISTAS
Para criar uma lista é assim:
Ex.: List nomes;

Para iniciar uma lista:
Ex.: List nomes = ["texto1", "texto2", "texto3",...] -> deve estar entre colchetes

Para criar uma lista de determinado tipo
Ex.: List<String>... -> aceita apenas itens do tipo String OU List<int>... -> aceita apenas itens do tipo inteiro; e assim por diante

Para acessar o valor da lista:
Ex.: 1º termo(duas formas) -> print(nomes.first) OU print(nomes[0])
Ex.: Último termo -> print(nomes.last)
Ex.: Acessando qualquer outro termo -> print(nomes[3])
