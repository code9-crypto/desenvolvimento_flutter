É uma linguagem que é fortemente tipada, ou seja, deve declarar o tipo
da variável antes do nome;
Exemplos:
int idade = 30;
String nome = "William";
...

OBS.: É possível fazer a multiplicação de caracteres assim:
"A" * 20 -> aqui vai gerar 20 letras A

PARÂMETROS DE FUNÇÕES
Para que seja possível "setar" um valor padrão e seja também opcionail,
apenas coloque o parâmetro entre colchetes [] e atribua um valor a ele;
NOTA: Dentro desses colchetes pode colocar mais de uma variável, porém
para que seja possível passar o valor ao segundo parâmetro sem passar pelo primeiro,
ocorrerá erro; então nesse caso deverá passar o valor a todos os parâmetros para que não haja erros;

Caso queria faze-lo de forma aleatória, ou seja, sem seguir a ordem dos parâmetros, é possível deixar os parâmetros entre chaves {}, porém agora
quando for chamar a função, a forma de passar os parâmetros devem ser nomeados;
Ex.:void main(){
	funcao(nome: "William", idade: 32);
}

funcao({String nome, int idade}){
	print("Olá $nome, sua idade é $idade);
}

---------------------------------------------------------------------------------------------------------------------------------
VALORES NULOS / NULL
Para que uma variável/parâmetro seja null, apenas específique o símbolo de ? depois do tipo da variável:
Ex.: String? nome

----------------------------------------------------------------------------------------------------------------------------------
OPERADOR TERNÁRIO
double nota = 8.5;
String mensagem = nota >= 6 ? "Aprovado" : "Reprovado"

OBS.: Para que seja possível uma variável receber um valor se for nulo ou que tenha valor utílizavel, usamos o operador ??;
Ex.: String cliente = nome ?? "não informado" -> Caso a variável nome tenha valor, então cliente receberá o valor da variável nome;
Caso a variável nome seja nulo ou undefined, então a variável cliente receberá o valor "não informado"

FUNÇÕES ANÔNIMAS
É passar uma função como parâmetro de outra função:
Ex.:
void main() {
  saudacoes(
    "William",
    corpo: (i){
    for( int j = 1; j <= i; j++ ){
      print("Olá $j");
    }
  });
}
o parâmetro corpo está recebendo uma função anônima

void saudacoes(String nome, {required Function(int) corpo}){
	corpo(10);
}
Para declarar um parâmetro como função, é deste jeito;(o atributo 'required' mostra que é obrigatório)
E para que uma função por parâmetro receba parâmetros, é deste jeito que é declarado

VARIÁVEIS DINÂMICAS
var -> é uma forma de declarar variável que não tem tipo específico, contudo se a variável iniciar com determinado tipo,
ela não poderá ser alterada para outro tipo no decorrer do script;
Ex.: var nome = "William";
var nome = 2; -> aqui causará um erro, portanto use apenas em casos muito específicos

dinamyc -> é uma forma de declarar variável que não tem tipo específico, mas este tipo aceita a troca do valor dentro da variável;
Ex.: dinamyc teste = "texto";
teste = 2 -> diferente da de cima, aqui não ocorrerá um erro, todavia não usa-a o tempo todo, faça isso em cenários muito específicos
para que não haja possível fatal erro no aplicativo;

num -> é uma forma de declarar variável que aceita apenas número, tanto inteiro como decimal e também pode ser alterado um pelo outro
no decorrer do script sem que haja erro;
Ex.: num numero = 50; 
num numero = 6.5;

LISTAS
Para criar uma lista é assim:
Ex.: List nomes;

Para iniciar uma lista:
Ex.: List nomes = ["texto1", "texto2", "texto3",...] -> deve estar entre colchetes

Para criar uma lista de determinado tipo
Ex.: List<String>... -> aceita apenas itens do tipo String OU List<int>... -> aceita apenas itens do tipo inteiro; e assim por diante

Para acessar o valor da lista:
Ex.: 1º termo(duas formas) -> print(nomes.first) OU print(nomes[0])
Ex.: Último termo -> print(nomes.last)
Ex.: Acessando qualquer outro termo -> print(nomes[3])

FUNÇÕES DE LISTAS
Vamos usar os exemplos com esta lista: List<int> idades = [](também pode ser declarado vazio)

idades.add(5) -> adiciona um valor à lista na última posição
idades.addAll([2,3,4,5,6]) -> adiciona uma lista de valores dentro da lista idades
idades.insert(int pos, valor) -> adiciona um valor à lista idades, numa posição específica
idades.contains(5) -> verifica se o valor está contido na lista e retorna(usado com print) true or false
idades.indexOf(5) -> retorna(usado com print) em qual posição está o valor determinado
idades.remove(5) -> remove o valor determinado da lista
idades.remoteAt(2) -> remove o valor da lista com base na posição informada como parâmetro
idades.shuffle() -> embaralha toda a lista
idades.clear() -> apaga todos os valores da lista

ITERAÇÃO DO LISTAS
List<String> nomes = ['william','ester','hadassa']
1º Exemplo(menos indicado):
for ( int i = 0; i <= nomes.length -1; i++){
	print(nomes[i].toUpperCase());
}

2º Exemplo(mais indicado e mais legível):
for (String nome in nomes){
	print(nome.toUpperCase());
}

TAMBÉM PODE FAZER UM LIMITE NA LISTA
for(String nome in nomes.sublist(2, 4)){
	print(nome.toUpperCase());
}


3º Exemplo(menos indicado):
nomes.forEach((nome) {
	print(nome.toUpperCase());
})

TAMBÉM PODE FAZER UM LIMITE NA LISTA
nomes.sublist(2,4).forEach((nome) {
	print(nome.toLowerCase());
})

TRATAMENTO DE EXCEÇÃO TRY/CATCH
estrutura:
try{

}catch(e){

}

É possível pegar qual o erro exato que está acontecendo com o parâmetro do catch;
Ex.: ...catch(e){ print(e.runtimeType) }...
E com este erro, podemos aprimorar mais o tratamento de erro dentro da estrutura do try/catch;
Supondo que o exemplo acima tenha impresso na tela o erro: UnsupportedError;
Adicionamos este erro na estrutura deste jeito:
DETALHE: ESTE TRATAMENTO DEVE SER FEITO SEMPRE ANTES DO CATCH E PODE SER ADICIONADO QUANTOS FOREM NECESSÁRIOS
try{

}on UnsupportedError{

}catch(e){

}

Desta forma, o código que der este erro, irá cair direto no erro descrito e não mais no catch

EXCEÇÕES PERSONALIZADAS
Primeiro criamos uma classe e implementamos da interface Exception;
Depois de criar a classe, criamos o método toString() que é na verdade uma sobrescrita
class excecao implements Exception{^
	String toString(){
		return "Este valor é inválido";
	}	
}

Depois de criada, lançamos a exceção com base em determinada condicional;
Ex.:
void funcao(int x){
	if( x <= 0 ){
		trow excecao();
	}
}

Agora podemos chamar a função normalmente na função main();
void main(){
	try{
		funcao(-10);
	}catch(e){
		print(e);
	}
}

Neste cenário, como o valor é menor que 0, então a exceção será lançada, caso fosse mair que 0, então continuará o programa normalmente
