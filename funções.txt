IMPORTANTE: ESSAS FUNÇÕES SEMPRE IRÃO DENTRO DE UM Container() OU DENTRO DE UM Scaffold()
Text() -> nela é possível inserir os textos e também estilizá-los com o parâmetro descrito
Ex.:
Text(
    "Pode entrar!",
    Aqui é a estilização
    style: TextStyle(
        fontSize: 40, color: Colors.white, fontWeight: FontWeight.w800),
        letterSpacing: 0.5 -> //este parâmetro deixa o espaçamento entre as letras no texto
),

Column() -> é aquela que alinha todos elementos de forma vertical
Ex.: Column(
    mainAxisAlignment: MainAxisAlignment.center, -> normalmente sempre dentro da coluna vem este elemento para centralizar os widgets. Este alinha no meio da tela, porém o tamanho da coluna ocupda a tela inteira
    mainAxisSize: MainAxisSize.min -> este elemento faz com que a coluna ocupe o mínimo possível de acordo com os widgets na tela.
)

Center() -> este é o widget que faz os itens ficarem centralizados, bem no meio da tela

children[] -> recebe uma lista de filhos, onde podem ser botões, textos ...
OBS.: aqui dentro desta lista, não precisa declarar os parâmetros como nomeados, apenas digite a função que deseja inserir

SizedBox() -> põe um espaçamento entre os elementos; recebe como parâmetro: width ou height
Ex.: SizedBox(height: 30)

//AQUI TAMBÉM TEM A INSERÇÃO DA IMAGEM
Container() -> para que seja possível inserir uma imagem no aplicativo, a função Column() e todo seu conteúdo deverá ficar
dentro do Container(), como child:
OBS.: Também muito usado para manter uma proporção de determinado widget(imagem, card, etc...)
Ex.: Container(
    padding: EdgeInsets.all(8.0),
    width: 120.0,
    margin: const EdgeInsets.symmetric(vertical: 2), -> este elemento permite dar margem aos itens; É semelhante ao padding
    //Este boxDecoration é o plano de fundo( caixa ) onde fica o filho dela, onde é configurado conforme abaixo: cores, arrendondamento, imagem ...
    decoration: BoxDecoration( -> Permite arredondar o item, semelhante ao button, mas com alguns parâmetros pouco diferentes
        borderRadius: BorderRadius.circular(10),
        shape: BoxShape.circle, //este BoxShape.circle deixa a caixa com arredondamento perfeito
        color: Colors.grey[200],
        image: DecorationImage(
          image: AssetImage("caminho_da_imagem")
        ),
        border: Border( //com este parâmetro é possível definir quais bordas irão aparecer e seus ajustes
          top: BorderSide(color: Colors.grey, width: 1.0),
          bottom: BorderSide(color: Colors.grey, width: 1.0),
        ),
      )
    child: Column(
        //Este elemento faz com que o item fique horizontalmente alinhado(start - esquerda, center - centro, end - direita); também conhecido como eixo cruzado
        crossAxisAlignment: CrossAxisAlignment.start,
        ....
    )
)

ESPAÇAMENTO
Padding(
    padding: const EdgeInsets.symmetric(horizontal/vertical: 16) -> este comando e espaçamento da a mesma simetria de espaçamento tanto na vertical ou horizontal
)

Expanded() -> esta função faz com que o elemento o ocupe a maior área possível, ou seja, caso haja um botão do lado, então ele vai ocupar até o espaço do botão
OBS.: Normalmente esta função é usada dentro da função Row()

BOTÕES (serve para )
TextButton(onPressed: onPressed, child: child) -> este é um widget que cria um botão e nele há dois parâmetros: 
1º função do botão
2º o filho do botão, ou seja, o que tem dentro do botão(normalmente um texto)

TextButton.styleFrom() -> é onde podemos personalizar o botão
padding: const EdgeInsets.all(50) -> com esta linha de código inserimos padding em todos os lados
padding: const EdgeInsets.only(top: 20, left: 20, right: 10, bottom: 30) -> permite personalizar onde ficará os tamanhos
shape: RoundedRectangleBorder( -> onde é possível arredondar o botão
    borderRadius: BorderRadius.circular(20) -> é este parâmetro que arredonda o botão
    side: BorderSide(color: Colors.black) -> onde inseri uma linha em volta do botão
    fixedSize: const Size(100, 100)
)

ElevatedButton(onPressed: login, child: Icon(Icons.login)) -> este parece ser um botão mais estilizado que o de cima
OBS.: os estilos usados acima, também servem para este botão

ElevatedButton.styleFrom( -> é onde podemos personalizar o botão
  padding: const EdgeInsets.all(50) -> com esta linha de código inserimos padding em todos os lados
  padding: const EdgeInsets.only(top: 20, left: 20, right: 10, bottom: 30) -> permite personalizar onde ficará os tamanhos
  fixedSize: const Size(100, 100) -> define o tamanho do botão
  shape: RoundedRectangleBorder( -> onde é possível arredondar o botão
      borderRadius: BorderRadius.circular(20) -> é este parâmetro que arredonda o botão
      side: BorderSide(color: Colors.black) -> onde inseri uma linha em volta do botão
  )
)

NOTA: Caso queira que um botão será desabilitado ou habilitado para que seja clicável, mas de forma programática, então usamos o operador ternário
no parâmetro nomeado onPressed desta forma:
Ex.: ElevatedButton(
  ...
  onPressed: campo.isNotEmpty ? (){} : null -> caso o campo não estaja vazio, então o botão será clicável(pois receberá alguma ação);
  será desabilitado(pois receberá o valor null)
)

FAZENDO TRANSIÇÃO DE TELAS USANDO O CONSTRUTOR PageView
OBS.: esta é uma classe com o construtor PageView, o qual é necessário ter um PageControler para fazer o controle de transição das páginas
NOTA: Cada um daquele Scaffold é um tela difirente

class HomeScreen extends StatelessWidget {
  HomeScreen({super.key});

  //****CONTROLADORES****
  final _pageController = PageController(); //este controlador será o responsável ir para à página desejada

  @override
  Widget build(BuildContext context) {
    //Este construtor PageView permite fazer a transição entre telas de forma bem simples
    return PageView(
      controller: _pageController,
      physics: NeverScrollableScrollPhysics(), //Este comando não permite fazer transição de telas arrastando o dedo
      children: [
        //Este é a primeira página(page 0)
        Scaffold(
          body: HomeTab(),
          //Para que seja possível criar um Drawer, este deverá ficar dentro de um Scaffold e é declarado desta forma
          drawer: CustomDrawer(_pageController),
        ),
        //Este é a segunda página(page 1)
        Scaffold(
          appBar: AppBar(
            title: Text("Produtos"),
            centerTitle: true,
          ),
          drawer: CustomDrawer(_pageController), //O drawer da página
          body: Container(), //Corpo da página
        )
      ],
    );
  }
}

class DrawerTile extends StatelessWidget {

  //***VARIÁVEIS****
  late IconData icon;
  late String text;
  late PageController controller;
  late int page;

  //***CONSTRUTORES****
  DrawerTile({super.key});
  DrawerTile.loja(this.icon, this.text, this.controller, this.page); //O controller e o page estão vindo do arquivo custom_drawer.dart que faz o controle da transição das páginas

  @override
  Widget build(BuildContext context) {
    //Está sendo retornado o Material para que seja possível causar um efeito ao clicar no item
    return Material(
      color: Colors.transparent,
      child: InkWell(
        onTap: (){
          Navigator.of(context).pop();
          //Aqui está indo para à página que veio por parâmetro no construtor
          controller.jumpToPage(page);
        },
        child: Container(
          height: 60.0,
          child: Row(
            children: [
              Icon(
                icon,
                size: 32.0,
                color: controller.page!.round() == page ? Theme.of(context).primaryColor : Colors.grey[700]
              ),
              SizedBox(width: 32.0,),
              Text(
                text,
                style: TextStyle(
                  fontSize: 16.0,
                  color: controller.page!.round() == page ? Theme.of(context).primaryColor : Colors.grey[700]
                ),
              )
            ],
          ),
        ),
      ),
    );
  }
}
