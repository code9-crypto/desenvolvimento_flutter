QuerySnapshot -> é usado para obter vários documentos(lista de documentos)
DocumentSnapshot -> é usado para obter um documento(foto)

INICIALIZANDO O BANCO
OBS.: este comando deve ser usado no main.dart dentro da função main() antes do runApp()
WidgetsFlutterBinding.ensureInitialized();
await Firebase.initializeApp();

OBTENDO TODOS OS DADOS DE UM VEZ
//OBS.: este firestore vem de uma constante feita assim:  FirebaseFirestore firestore = FirebaseFirestore.instance;
firestore.collection("users").snapshots(); 

OBTENDO OS DADOS DO BANCO APENAS UMA VEZ
//aqui este comando está pegando os dados do banco(nas coleções descritas) apenas uma vez
//OBS.: este firestore vem de uma constante feita assim:  FirebaseFirestore firestore = FirebaseFirestore.instance;
firestore.collection("users").doc(uid).collection("orders").get();

OBTENDO OS DADOS DO BANCO
//este comando retorna um QuerySnapshot; OBS.: este resultado vem no futuro
QuerySnapshot snapshot = await FirebaseFirestore.instance.collection("coleção").get(); -> este comando está pegando tanto os documentos(ID's) quanto seus respectivos campos

LENDO OS DADOS OBTIDOS DO BANCO
snapshot.docs.forEach((d){
    print(d.data)
}); 

OU

    print(doc.data)
}
